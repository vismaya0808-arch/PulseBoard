# PulseBoard

PulseBoard is a mini social media web application built with HTML, CSS, JavaScript, Node.js, and Express.js.

## Features
- User registration and login
- User profiles
- Create posts
- Like and comment on posts
- Follow other users

## Technologies
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- JSON-file storage

## Run Locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000` in your browser.
